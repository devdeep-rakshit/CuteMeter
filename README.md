# CuteMeter 🎀

A playful, mobile-first web experience that provides a fun test of your legendary cuteness. 

## Features
- **Live Camera Experience**: Uses your front camera directly in the browser.
- **10-Second Countdown**: Playful holding animation.
- **Cute Scores & Compliments**: Generates wholesome compliments and fun scores!
- **Privacy First**: Processed entirely locally. No images are saved, captured, or transmitted.
